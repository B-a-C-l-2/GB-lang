# GB 成绩管理应用

运行：`python -m gb apps/grades/main.gb`

功能：三科成绩录入、列表、学号查询、成绩修改、确认删除、总分排名、
平均分及及格统计、精确姓名查询。学号唯一，成绩为 0–100 的整数。
排名按总分降序、同分按学号升序，名次为顺序号。姓名可以重复。
数据只保存在内存，退出后清空；任意提示处遇 EOF 都安全结束。
录入/修改未完成时不写入数据。删除必须输入小写 y 确认。

## 演示顺序
1. 选择 1，录入学号 1、姓名 Alice、成绩 80 / 90 / 100。
2. 再录入学号 2、姓名 Bob、成绩 50 / 60 / 70。
3. 选择 2 查看列表，选择 6 查看排名，选择 7 查看统计。
4. 选择 4 修改 Bob 为 100 / 100 / 100，再查看排名。
5. 选择 3 按学号查找，选择 8 按姓名查找。
6. 选择 5 删除一个记录，选择 0 退出。

验证：`python apps/grades/test_app.py`。
外部运行器只提供固定 stdin 并检查 stdout/stderr/退出码，业务全部由 GB 实现。
语言自身的黑盒测试仍为 `python -m gb tests/selftest.gb`。

## 结构
Student 保存记录，students 数组保存全部记录。
readText/readInt 统一输入验证；findId/total/show 为通用操作。
各菜单功能拆成函数，main 负责分派；排序采用冒泡，删除左移后 pop。
无需修改解释器，也不依赖文件、网络或第三方库。
